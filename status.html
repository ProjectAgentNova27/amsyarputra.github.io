Reading the signals

Online means the hostname responded normally. Protected means Cloudflare Access or authentication blocks public access. Offline means the hostname check failed, with the cause still unconfirmed. Unknown means the status API did not supply a usable result.

Amsyar Lab requires Cloudflare Access. A Protected result confirms only its login gate. Mini Booth uses the existing booth key; a missing result does not establish that the photobooth is offline.
