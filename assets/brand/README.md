# AP. Identity

Owner-approved on 9 October 2026 for future portal and Mini Hosting branding.
Preserve the existing lowercase `ap.` form: Inter Bold (700), zero letter spacing,
with a cyan full stop. Do not substitute an uppercase/redesigned mark by default.
The live navigation remains accessible text, using the same local font and colors.

Canonical artwork: outlined SVG, no runtime fonts required. Square 512-unit artboard
with clear space. `on-dark` uses light lettering/cyan; `on-light` uses dark
lettering/teal; `mono` is single-color dark lettering. Transparent PNG/WebP exports
are 1024px. JPEG has an appropriate opaque background. PDF preserves vector paths.
ICO contains 16/32/48/64/128/256px variants. These are practical interchange formats,
not proprietary AI/PSD sources. SVG is the editable vector master.

Download [complete kit](ap-brand-kit.zip), or individual files in this directory.
Use SVG for web/vector work, PDF for print, PNG for general sharing, WebP for web
raster work and ICO for compatible app/site icons. Do not replace existing favicons
or all application branding automatically: each service change needs scoped review.

Derived from the bundled Inter font under its [SIL OFL license](../fonts/LICENSE.txt).
Reproduction: tests/export-brand.py requires fonttools/Brotli; export-brand.cjs uses
sharp, pdf-lib and jszip. These are development tools, not website dependencies.
