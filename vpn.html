VPN Access

PRIVATE NETWORK

Private access only.
WireGuard configuration files, QR codes, private keys, DDNS fallback links, and internal service addresses are not published here.

Purpose

Use WireGuard VPN to securely access selected home network services when away from home. This is intended for private use only.

Recommended Use

  • Connect to WireGuard before accessing private services.
  • Use VPN for Sunshine / Moonlight game streaming.
  • Use VPN for router, NAS, and other internal dashboards.
  • Disconnect when no longer needed.

Router Access

The router portal link uses Cloudflare Access when available. If Cloudflare Access or the tunnel is offline, connect to WireGuard first and access the router using its private LAN address.

Direct DDNS router-admin fallback URLs are intentionally not shown on this public page.

Moonlight / Sunshine

Sunshine Admin is protected through Cloudflare Access. Actual Moonlight game streaming should still use WireGuard VPN.
  • Sunshine Admin: https://sunshine.amsyarputra.net
  • Game streaming path: WireGuard → Moonlight → Gaming PC VPN/LAN IP
  • VPN type: WireGuard
  • Recommended mobile MTU: 1280
  • Sunshine PC must be powered on.
  • Moonlight may need manual host entry if auto-discovery does not work over VPN.
  • For manual Moonlight pairing, use the gaming PC's VPN IP instead of your public IP.

Security Notes

  • Do not share VPN profiles publicly.
  • Do not upload WireGuard QR codes to this website.
  • Do not expose router or NAS admin pages directly to the internet.
  • Do not publish direct DDNS router admin URLs on the public portal.
  • Do not expose Sunshine streaming ports directly to the internet.
  • Use strong device passwords and keep Sunshine updated.
  • Only create VPN profiles for devices you trust.

Quick Flow

  • Install WireGuard on your phone, tablet, or laptop.
  • Import your private WireGuard profile locally.
  • Connect to VPN.
  • Open Moonlight.
  • Add the gaming PC manually using its VPN IP.
  • Start streaming through Sunshine.
