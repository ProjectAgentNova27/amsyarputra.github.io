PRIVATE ACCESS

Access model

Private home services should be accessed through Cloudflare Access, VPN, or local network access. Router port forwarding should not be used unless explicitly required and properly secured.

Admin services are not intended to be public. Cloudflare Access should remain enabled for private hostnames.

Emulator is public and needs no VPN or Cloudflare Access login. Its LAN address, https://emu.lan.amsyarputra.net, is for home-network or home-VPN access. Browser saves are separate for the two addresses.
